Map Extractor - home-screen web app

Host this folder on any static HTTPS host, open it in Safari on your iPhone,
then Share > Add to Home Screen. It launches full screen, works offline after
the first visit, and "Save to Files..." sends the maps to Files, AirDrop or Photos.

Quickest hosts (free):
- GitHub Pages: new public repo > Add file > Upload files (drop everything in
  this folder) > Settings > Pages > Deploy from branch: main, / (root).
  Your app lives at https://<you>.github.io/<repo>/
- Netlify Drop: app.netlify.com/drop, drag this folder onto the page, then
  claim the site with a free account so it does not expire.

Everything runs on the phone; images never leave it.
